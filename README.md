# Python-Project
This repository contains the python project i have done as part of my DSML course at Entri

Project Overview
This project involves analyzing employee data from ABC Company, consisting of 458 rows and 9 columns. The objective is to preprocess the dataset, perform analytical tasks, and visualize key findings to provide meaningful insights about the company's workforce.

Preprocessing Steps
Data Cleaning: Ensured data consistency and integrity before analysis.
Height Column Correction: Replaced missing or incorrect values in the "Height" column with random numbers between 150 and 180.

Analysis Tasks & Visualizations
1) Employee Distribution by Team
Determined the percentage of employees in each team.
Visualization: Bar chart.

2) Employee Segregation by Position
Categorized employees based on their positions in the company.
Visualization: Bar chart.

3) Predominant Age Group
Identified the most common age group among employees.
Visualization: Horizontal bar chart.

4) Highest Salary Expenditure (Team & Position-wise)
Analyzed which team and position account for the highest total salary expenses.
Visualization: Line chart.

5) Correlation between Age and Salary
Investigated the relationship between age and salary to check for trends.
Visualization: Scatter plot with regression line

Insights
1. The highest number of employees are in New Orleans Pelicans.
2. The highest number of employees holds the position of SG.
3. The predominant age group is 20-30.
4. The team Cleveland Cavaliers and Position C has the highest salary expenditure.
5. There is a weak positive relationship between age and salary
